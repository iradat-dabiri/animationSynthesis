3rd Year Project - Animation of Avatars Using Motion Capture Data

To parse the Acclaim Motion Capture and Acclaim Skeleton File files visually, I have adapted the following C++, with OpenGL and FLTK for interfacing.
Jernej Barbic and Yili Zhao at USC, ASF/AMC viewer
http://mocap.cs.cmu.edu/tools.php

To run this program, you can build in Microsoft Visual Studio, changing the file variables, and walk lengths to create the file preferred. 
Once calculated, the FLTK interface will pop up, and allow you to run the new AMC file.
